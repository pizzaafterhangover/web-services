- 대표 노드 control_master(controller_manager)가 hardware component 2개(팔 OpenCR, 스월브 OpenCR)를 맡고, 그 안에서 컨트롤러들이 실행된다.
- 모든 파트 공통: `/diagnostics`는 판단으로 보내고, `/state/*`는 판단에서 받는다.
- 안전 정지에서 제어는 2단계인 명령 타임아웃을 맡는다.

## 노드 목록

대표 노드는 ★로 표시했다. 전체 페이지의 노드 목록에서 이 파트만 옮겼다.

| 노드 | 하는 일 | 구분 |
| --- | --- | --- |
| ★ control_master (controller_manager) | hardware component 2개(OpenCR #1 팔, #2 스월브) | 기존 패키지 (ros2_control) |
| swerve_controller | `/cmd_vel` → 스월브 8모터, `/odom` 발행(TF는 끔) | 미정 (직접 작성 / 기존 패키지) |
| 팔 JTC, 그리퍼 컨트롤러 | 받은 궤적·그리퍼 명령대로 실행 | 기존 패키지 |
| joint_state_broadcaster, imu_broadcaster | `/joint_states`, `/imu` 발행(IMU 보드 미정) | 기존 패키지 |
| velocity_smoother, collision_monitor | 급가속·급감속 제한, 전면 점구름으로 감속·정지 후 최종 `/cmd_vel` 발행 | 기존 패키지 |
| twist_mux (선택) | 수동 조작 시험용. 디버그 launch에만 | 기존 패키지 |

## 통신 규칙

- **안전은 맨 뒤에 둔다.** 모든 속도 명령은 Nav2 복구 동작까지 포함해 velocity_smoother → collision_monitor를 거쳐 `/cmd_vel`이 된다. 접촉하면 실격이라 이 체인은 빼지 않는다.
- **속도 명령은 체인 전체 TwistStamped.** 최근 ROS 2 배포판의 Nav2와 컨트롤러 기본값에 맞춘다.
- **안전 정지 3단**: planning_master 입력 타임아웃 → control_master 명령 타임아웃 → 펌웨어 watchdog.
- **control_master(controller_manager)는 하나.** hardware component는 OpenCR별로 2개(팔, 스월브)를 올린다. IMU는 OpenCR 보드 내장 IMU를 쓰고, 어느 보드의 IMU인지는 **[미정]** 이다.
- 스월브 컨트롤러는 TF를 끄고 `/odom` 토픽만 낸다.
- **odom → base_link**: localization(인지) 하나만 낸다.
- base_link = 차체 중심, 바닥 높이. x는 앞, y는 왼쪽, 단위는 m와 rad (REP-103).
- 팔 제어는 TF로 arm_base_link 기준으로 바꾼다. 장착 위치 숫자를 코드에 넣지 않는다(장착 위치 [미정]).

인지가 줄여서 보내고, 팔 제어는 받은 값을 바로 롤 각도로 쓴다.

| 퍽 상태 | 대칭 | 보낼 범위 |
| --- | --- | --- |
| 서 있는 원통 | 어느 방향이든 같음 | 0 고정 |
| 서 있는 직육면체 | 90°마다 | −45°에서 +45° |
| 누운 원통 · 직육면체 | 180°마다 | −90°에서 +90° |

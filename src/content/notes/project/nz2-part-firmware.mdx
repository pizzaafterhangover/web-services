- 대표 노드는 OpenCR 보드 2대다. 펌웨어는 제어 파트가 맡는다.
- 보드마다 USB CDC로 상위 명령을 받아 전류·속도를 제한한 뒤 DXL TTL로 다이나믹셀을 구동하고, 200 ms 동안 명령이 없으면 watchdog이 멈춘다.
- 안전 3중: control_master(타임아웃 200 ms · E-stop) → OpenCR 펌웨어 watchdog(200 ms) → E-stop 릴레이로 12 V 모터 전원 차단.

## 토픽 · 서비스 · 액션

펌웨어는 ROS 토픽·서비스·액션을 직접 주고받지 않는다. 다른 파트·하드웨어와는 아래처럼 연결된다.

| 연결 | 보내는 쪽 → 받는 쪽 | 비고 |
| --- | --- | --- |
| USB CDC | swerve_bridge ↔ OpenCR #1 | |
| USB CDC | arm_bridge ↔ OpenCR #2 | |
| DXL TTL | OpenCR #1 → 구동 ID 1-4, 조향 ID 5-8 | |
| DXL TTL | OpenCR #2 → 팔 ID 11-14, 그리퍼 15, 롤 16 | |
| 12 V 전원 차단 | 비상정지 스위치 → 12 V 모터 전원 릴레이 | 하드웨어 |

## 통신 규칙

- **안전 3중**: control_master(타임아웃 200 ms · E-stop) → OpenCR 펌웨어 watchdog(200 ms) → E-stop 릴레이로 12 V 모터 전원 차단(하드웨어).
- **스월브 역기구학은 Jetson에서** 계산한다(swerve_kinematics). OpenCR은 전류·속도 제한과 200 ms watchdog만 맡고, 상위 명령을 통과시킨다.

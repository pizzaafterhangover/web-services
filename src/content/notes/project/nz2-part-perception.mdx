- 위쪽은 위치 추정이다. odom → base_link는 ekf_node만, map → odom은 amcl만 낸다. slam_toolbox는 매핑 모드에서만 띄운다.
- 아래쪽은 인식이다. 결과는 대표 노드 perception_master가 모아 `/perception/state`로 낸다. 신호등 결과는 traffic_behavior로도 바로 간다.
- **[검토 중]** 퍽 3D 매핑 경로: 전면 depth가 퍽에 연결되지 않았고(puck_localizer는 그리퍼 depth만 받음), 순회 중 매핑 방법이 미확정이다.

## 노드 목록

대표 노드는 ★로 표시했다. 전체 페이지의 노드 목록에서 이 파트만 옮겼다.

| --- | --- | --- |
| ★ perception_master | 인지 결과 집계, 상태 감시. `/perception/state` 발행, `/perception/set_mode` 서비스 | 직접 작성 |
| realsense2_camera (`/front`, `/gripper`) | 전면: 컬러, depth, infra1·infra2. 그리퍼: 컬러, color에 정렬된 depth | 기존 패키지 |
| isaac_ros_cuvslam | 시각 오도메트리 30 Hz | 기존 패키지 |

| depthimage_to_laserscan | 전면 depth → 2D 스캔 `/scan` | 기존 패키지 |
| map_server | 매핑 때 만든 `map.yaml` 로드 | 기존 패키지 |
| amcl | 맵 기반 보정(OmniMotionModel). map → odom 발행 | 기존 패키지 |
| slam_toolbox | 매핑 모드 전용. 매핑 후 map_saver로 저장 | 기존 패키지 |

| apriltag_detector | AprilTag 검출(tag36h11 **[가정]**) | 미정 |

## 통신 규칙

- 받는 쪽이 '안 보임'과 '노드 고장'을 구분할 수 있도록, 인지 토픽은 결과가 없어도 항상 발행한다.
- 카메라 영상이 약 130 MB/s라 composable node와 intra-process 통신으로 복사 비용을 줄인다.
- **odom → base_link**: ekf_node 하나만 낸다.
- **map → odom**: amcl 하나만 낸다.
- **base_link → camera_link, gripper_cam**: robot_state_publisher가 URDF와 관절 상태로 낸다.
- TF는 최신 값이 아니라 영상의 `header.stamp` 시각으로 조회한다.

## 개요

KANT PA1 LV2 프로젝트2 **팀NZ2**의 로봇은 RGB 퍽을 선반에서 선반으로 옮기는 모바일 매니퓰레이터다.

| 항목 | 내용 |
| --- | --- |
| 차체 | 스월브 4모듈 |
| 팔 | OpenMANIPULATOR-X 개조 (손목 롤 추가) |
| 연산 | Jetson Orin Nano Developer Kit |
| 구동 보드 | OpenCR 1.0 2대. #1은 팔(다이나믹셀 ID 11-16), #2는 스월브(ID 1-8) |
| 역할 | 인지 · 제어 · 판단(팀장, 테크리드) |

## 공통 약속

- 단위는 m, rad, s만 쓴다 (REP-103).
- 퍽 위치는 로봇 기준 좌표로 다루고, 좌표 변환은 TF로 한다.
- 그리퍼 카메라·거리 센서·신호등·QR 토픽은 센서 연결 방식과 대회 규칙이 정해진 뒤 추가한다.
